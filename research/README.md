# Blaque Baux BRICS — research

Path-A research plan for the BRICS sleeve. Nothing here is run yet; this directory holds the
sketches once they land. The hard gate is **tradability** — Russia is excluded (untradable for a US
book), China VIE/delisting risk is sized not waved away.
